Voting Tool — User Guide

Everything you need to find a project, cast a vote, and (for admins) manage projects and users. Pick your role below to jump to the right section.

Before you start
  • Sign in with your Microsoft account registered for the tool. There is no self sign-up.
  • Use a desktop browser for the best experience.
  • Have your score and a short written reason ready — the reason is required.
How to vote on a project
  1. 1
    Open “Voting R&D Projects” from the home page.

    You'll see a search box to find a project.

  2. 2
    Search by project code or name.

    Start typing and pick your project from the list. Only projects you can still vote on will appear.

  3. 3
    Review the project details.

    Check the name, phase and documents. These fields are read-only — if something's wrong, reset and ask an admin to fix the project.

  4. 4
    Give a score from 1 to 5.

    1 is low, 5 is high. Sales & Marketing rate market potential; technical voters rate probability of success.

  5. 5
    Write a short reason, then submit.

    A green message confirms your vote was saved. You can then pick another project or go back home.

One vote per project. Once you vote, that project drops off your list so you can't vote twice on the same record.
Power BI reporting
  • Open “Power BI Dashboard” from home to see voting results and trends.
  • Use filters to narrow the view; reset them before starting a new question.
  • Results refresh twice a day, so a fresh vote may not appear immediately.
Golden rule. Phase, status and visibility are three different things. Change only what you mean to change.
Create a project
  1. 1
    Open “Create Project”.

    Fill in code, name, region, segment, innovation area, phase and status.

  2. 2
    Attach files if needed.

    Use the file picker — don't paste a manual SharePoint link. The system builds the folder for you.

  3. 3
    Submit.

    A new project is created. Set its visibility to Active when it's ready for voting.

Advance a project to a new phase

Use “Create New Project Phase” only when a project genuinely moves to a new phase.

  • Search and select the project, then choose the new phase.
  • This creates a new project record and keeps the old one as history.
  • Votes do not carry over — tell voters the new phase is a fresh voting object.
Update status & visibility
Status

Describes the project's business position (In Progress, On Hold, Completed, Killed). Does not control voting.

Visibility

Active = offered to eligible voters. Inactive = hidden from voting.

Update a user
  • Open “Update User Status” and search by email.
  • Confirm the department and status, then submit.
  • Changing a department keeps past votes intact by closing the old record and creating a new one.
  • You can't change another administrator's status here — use the official identity process.
